aiproxy

OpenAI-compatible proxy for multiple AI providers

Route multiple AI providers through one service, keep the public API stable, and let the proxy own model naming, authentication, alias routing, and failover behavior.

One API Surface

Expose OpenAI-compatible endpoints while mixing OpenAI, Anthropic, Gemini, and OpenAI-compatible backends.

Proxy-Owned Routing

Publish direct models and alias-backed virtual models without coupling clients to a single upstream provider.

Built For Operations

Validate config, reload routing state on SIGHUP, export Prometheus metrics, and keep credentials out of logs.
